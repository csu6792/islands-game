怎麼給全班用？

  1. 用下方提示詞，把教材丟給 Grok / Gemini / ChatGPT 轉成 Markdown
  2. 可直接將AI產生的MD檔上傳到GITHUB教材資料夾 並修改教材資料夾內的lessons.json若有多筆請依序增加並用逗號分開 如果選擇執行此方式就無需再往下執行其他步驟
  3. 把產出的 Markdown 貼上來（或上傳 .md）→ 按「預覽檢查」
  4. 確認無誤後「下載 lesson.md」或「lesson.json」
  5. 放到網站的 教材/ 資料夾（和知識島 HTML 同層下的資料夾）並推送
  6. 多教材可在 教材/lessons.json 列清單，學生用 ?lesson=檔名 開啟

① 複製提示詞 → 請 AI 轉教材

提示詞

打開 Gemini 打開 ChatGPT 打開 Grok

多教材（選用）

在 教材/ 資料夾放多個 .md / .json，並新增 教材/lessons.json：

{
  {
    "id": "solar",
    "title": "太陽系",
    "file": "太陽系.md"
  },
  {
    "id": "plants",
    "title": "植物的一生",
    "file": "植物.md"
  }
]

學生連結：知識島探險家.html?lesson=solar 或 ?lesson=太陽系.md（檔案實際在 教材/ 內）
